# Daily protocol — 45 phút (không bỏ quên)

**Khung giờ mặc định:** 05:45–06:30 (Asia/Ho_Chi_Minh), lặp hàng ngày trên Google Calendar.  
**Mục tiêu:** mỗi ngày ôn multi-omics / tín hiệu sớm + gắn 1 vấn đề Smart A / y tế số theo hướng phát hiện sớm–dọc–AI.  
**Goal:** ACTIVE · Chỉ **PI** tick DONE · STREAK thật = tiến độ.

## Định tuyến 30″ (làm trước checklist)

| Tình trạng | Mở file |
|------------|---------|
| STREAK &lt;3 | `PI-NEXT-45MIN` · `PI-SESSION-SCRIPT-STREAK3` · bridge #0 |
| MISS gần đây | `MISS-RESCUE-EARLY-SIGNAL-BRIDGE` (#14) — bậc A/B/C/D |
| STREAK ≥3 · ngày thường | Bridge theo `#12` + **EQ rotation** (T2/T4/T6) / drill |
| Chủ nhật / weekly | `weekly-review` · PB lens `#13` |

## Checklist (đúng thứ tự)

1. **Đọc (15′)** — 1 nguồn: curriculum Ngày N **hoặc** bridge rotation **hoặc** EQ-SA01|02|05 drill. Không scroll lan man.
2. **Ghi insight (10′)** — tối đa 5 dòng trong `research/daily-log/YYYY-MM-DD.md` (điền drill A/B nếu dùng study sheet).
3. **Gắn bài toán mình (15′)** — SA-01…05 hoặc y tế số; 1 câu lệch hướng Precure **hoặc** 1 hàng PB lens #13.
4. **Neo hành động (5′)** — 1 việc nhỏ ≤30′; tick **DONE** chỉ khi đủ tiêu chí `research/RITUAL-DONE-vs-PREP.md`.
